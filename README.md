# Matriz de investigación

Aplicación de escritorio para organizar y revisar artículos científicos mediante fichas, clasificaciones y un tablero visual.

## Descargas

Los instaladores disponibles están en [Releases](https://github.com/Juandiegolb99/matriz-de-investigacion/releases).

- **Windows:** instalador `Instalar-Matriz-Windows.exe`.
- **Linux:** paquete `.deb` para distribuciones compatibles o versión portable `.tar.gz`.
- Consulta `SHA256SUMS.txt` en cada versión para comprobar los archivos descargados.

En una instalación nueva se abre un proyecto de ejemplo que explica el uso. Tus matrices personales se guardan en archivos `.matrizdb` y no se incluyen en estas descargas.
