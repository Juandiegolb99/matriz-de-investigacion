# Nexo Académico

Aplicación de escritorio para organizar y revisar artículos científicos mediante fichas, clasificaciones y un tablero visual.

## Descargas

La versión actual es [Nexo Académico 1.0.0](https://github.com/Juandiegolb99/matriz-de-investigacion/releases/tag/v1.0.0).

- **Windows:** Instalar-Nexo-Academico-Windows.exe
- **Linux:** Nexo-Academico-Linux.deb o Nexo-Academico-Linux-portable.tar.gz
- Consulta SHA256SUMS.txt en la versión para comprobar las descargas.

El instalador de Windows aún no tiene un dictamen de Microsoft sobre la detección de la versión anterior. Si Defender o SmartScreen muestran una alerta, no la desactives ni fuerces la instalación mientras la revisión esté pendiente.

Los proyectos personales se guardan en archivos .matrizdb o .matriz. La versión 1.0.0 está preparada para abrir los proyectos creados con Matriz de investigación.

## Condiciones de uso

La aplicación se ofrece gratuitamente para uso personal y académico. No se permite venderla, cobrar por su acceso ni redistribuir los instaladores o versiones modificadas sin autorización escrita del autor.

El código fuente de la aplicación no se publica en este repositorio. GitHub genera automáticamente archivos “Source code” que contienen únicamente la documentación del repositorio; no incluyen el código de la aplicación.
